ینولایف — استایل تسویه حساب نسخه ۲، اصلاح‌شده برای وودمارت

این ZIP قالب یا افزونه نیست و نباید از بخش نصب قالب/افزونه بارگذاری شود.

روش استفاده:
۱. یک نسخه پشتیبان از CSS فعلی تسویه حساب نگه دارید.
۲. کدهای قبلی تسویه حسابی را که در این گفتگو دریافت کرده‌اید، از بخش CSS اضافی یا CSS سفارشی قالب حذف کنید. استایل‌های نامرتبط سایت را حذف نکنید.
۳. فایل woocommerce-checkout.css داخل این ZIP را با Notepad باز کنید.
۴. تمام محتوای فایل را بدون تگ style در «نمایش ← سفارشی‌سازی ← CSS اضافی» قرار دهید و انتشار را بزنید. نسخه جدید را به انتهای نسخه قبلی اضافه نکنید.
۵. کش افزونه بهینه‌سازی و کش CSS قالب را پاک کنید. صفحه را با Ctrl+F5 دوباره باز کنید یا در پنجره ناشناس امتحان کنید.
۶. با داشتن کالا در سبد، صفحه تسویه حساب را در دسکتاپ و موبایل بررسی کنید. استان/شهر، ارسال به آدرس دیگر، کوپن، خطاهای فرم و درگاه‌های خود را نیز آزمایش کنید؛ ترجیحاً ابتدا روی سایت آزمایشی.

چه چیزی اصلاح شده؟
- حذف سقف عرض ۵۰٪ وودمارت که فرم را دوباره نصف می‌کرد.
- قرار دادن کادر واقعی خلاصه سفارش در ستون چپ، کنار اطلاعات گیرنده.
- حذف کادر و فاصله‌گذاری اضافی وودمارت دور سفارش.
- جفت شدن استان/شهر و کدپستی/تلفن در دسکتاپ؛ تک‌ستونه شدن فیلدها در موبایل.
- نمایش خواناتر روش ارسال، کد تخفیف، فیلدها و دکمه پرداخت.

محدوده:
این فایل برای تسویه حساب کلاسیک ووکامرس است، نه بلوک Checkout.
قواعد چیدمان با CSS عمومی وودمارت 8.5.5 بررسی و روی نمونه ساختارهای آن آزمایش شده‌اند؛ اتصال به مدیریت وردپرس یا اجرای پرداخت واقعی انجام نشده است.
CSS فقط ظاهر را تغییر می‌دهد؛ فیلدها، قیمت، کوپن و درگاه همچنان توسط ووکامرس و افزونه‌های سایت اداره می‌شوند.
