# 🚀 راهنمای راه‌اندازی — گام به گام (ویندوز)

**هدف این مرحله:** ماشین تو با موفقیت به متاتریدر ۵ وصل بشه، اکانت دمو رو بشناسه،
کندل‌های زنده EURUSD رو بگیره و ذخیره کنه. اسم این milestone: **Heartbeat** 🫀

> **تفکیک مهم — سه چیزِ جدا:**
> 1. **ترمینال MT5** = نرم‌افزار خود بروکر (تو نصب داری ✅)
> 2. **VS Code** = فقط ویرایشگر کد
> 3. **پکیج پایتونی MetaTrader5** = پلِ کد ↔ ترمینال (این را الان نصب می‌کنیم)
>
> «متاتریدر روی VS Code» نصب نمی‌شود؛ پکیج پایتونی داخل VS Code نصب می‌شود.

---

## گام ۱ — نصب پایتون (اگر نداری)

1. برو به [python.org/downloads](https://www.python.org/downloads/)
2. **Python 3.11 یا 3.12** را دانلود و نصب کن
3. ⚠️ در اولین صفحه نصب حتماً تیک **«Add python.exe to PATH»** را بزن
4. چک کن — در CMD یا PowerShell:

```powershell
py --version
# باید چیزی مثل: Python 3.12.x
```

اگه دستور `py` کار نکرد و Microsoft Store باز شد → پایتون از Store نصب شده؛
حذفش کن و از python.org نصب کن.

## گام ۲ — دریافت و باز کردن پروژه

1. فایل `gnidart-trading-bot-v0.1.zip` را دانلود و extract کن (مثلاً در `C:\projects\gnidart-trading-bot`)
2. VS Code → **File → Open Folder** → پوشه پروژه را انتخاب کن
3. اگر VS Code پرسید «Do you trust the authors?» → Yes

## گام ۳ — نصب پکیج‌ها

در ترمینال VS Code (**Terminal → New Terminal**):

```powershell
py -m pip install --upgrade pip
py -m pip install -r requirements.txt -r requirements-win.txt
```

## گام ۴ — تست سلامت پروژه (بدون نیاز به MT5)

```powershell
py -m unittest discover -s tests
```

**انتظار:** `Ran 15 tests ... OK` — یعنی کد سالم روی ماشین تو اجرا می‌شود.
(برق‌گیر ضرر، موتور ریسک، ژورنال — همه تست‌شده)

## گام ۵ — اکانت دمو در MT5

1. ترمینال MT5 را باز کن
2. **File → Open an Account** (یا نوار پایین-راست: Connections → اضافه)
3. سریع‌ترین راه: **MetaQuotes-Demo** را از لیست انتخاب کن (اکانت مجازی رایگان)
   — یا اگر بروکر خاصی داری، همان را انتخاب کن
4. فرم کوتاه را پر کن → **اکانت دمو با پول مجازی ساخته می‌شود**
5. مطمئن شو در ترمینال لاگین هستی (پایین-راست باید شماره اکانت وصل نشان دهد)

## گام ۶ — تنظیمات ترمینال

1. دکمه **Algo Trading** در نوار ابزار بالا → **روشن** (سبز شود)
2. **Tools → Options → Expert Advisors** → تیک **Allow Algorithmic Trading**
3. در پنجره **Market Watch** (Ctrl+M) مطمئن شو **EURUSD** دیده می‌شود؛
   اگر نیست: راست‌کلیک → **Show All**

## گام ۷ — اجرای Heartbeat 🫀

در ترمینال VS Code (ترمینال MT5 هم باز بماند):

```powershell
py scripts/mt5_heartbeat.py
```

**خروجی مورد انتظار:**

```
============================================================
 اکانت  : 12345678 @ MetaQuotes-Demo
 بالانس : 10,000.00 USD | لوریج 1:100
 نوع    : ✅ دمو (درست همینه)
============================================================
EURUSD: bid=1.08xxx  ask=1.08xxx  spread=xx points

500 کندل بسته‌شده M15 | بازه: ... → ...
...
✅ ذخیره شد: data\mt5_EURUSD_M15.csv
HEARTBEAT OK — قلب ربات می‌تپد. 🫀
```

## گام ۸ — گزارش به منتور

کل خروجی (متن یا اسکرین‌شات) را در چت بفرست — مخصوصاً:
- نوع اکانت (دمو بودنش مهم است!)
- مقدار **spread** (برای انتخاب بروکر واقعی بعدی حیاتی است)
- چند خط آخر جدول کندل‌ها

## 🔧 رفع اشکال

| مشکل | راه‌حل |
|---|---|
| `py` شناخته نشد / Store باز شد | پایتون از python.org نصب کن با تیک PATH |
| `MetaTrader5` نصب نشد | نسخه پایتون را چک کن (3.9 تا 3.12) — `py --version` |
| `اتصال به ترمینال MT5 ناموفق` | ترمینال باز است؟ لاگین هستی؟ اگر چند ترمینال داری، مسیرش را به `MT5DataProvider(terminal_path=...)` بده |
| `سیمبل 'EURUSD' پیدا نشد` | بروکرت پسوند دارد: `py scripts/mt5_heartbeat.py --symbol EURUSD.r` (پسوند را از Market Watch کپی کن) |
| کندل آخر دیشب متوقف شده | بازار فارکس آخر هفته تعطیل است — داده تاریخی کامل هست، فقط قیمت لحظه‌ای ندارد |

## بعد از Heartbeat چه می‌شود؟

- **اینجا (سندباکس):** فاز ۰-ب (پایپ‌لاین داده Dukascopy) و فاز ۱ (موتور بک‌تست) ساخته می‌شود
- **ماشین تو:** در فاز ۵ تبدیل به «گره اجرای دمو» می‌شود — همان کد، همان منطق
- **قانون طلایی پروژه:** هیچ پول واقعی‌ای وارد بازی نمی‌شود تا وقتی سیستم
  بک‌تست walk-forward و ۲-۳ ماه فوروارد دمو را پاس کند
