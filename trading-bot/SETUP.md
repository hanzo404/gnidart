# 🚀 راهنمای راه‌اندازی — گام به گام (ویندوز)

**هدف این مرحله:** ماشین تو با موفقیت به متاتریدر ۵ وصل بشه، اکانت دمو رو بشناسه،
کندل‌های زنده **XAUUSD (طلا)** رو بگیره و **داده تاریخی** را برای بک‌تست صادر کنه.

> **تفکیک مهم — سه چیزِ جدا:**
> 1. **ترمینال MT5** = نرم‌افزار خود بروکر (تو نصب داری ✅)
> 2. **VS Code** = فقط ویرایشگر کد
> 3. **پکیج پایتونی MetaTrader5** = پلِ کد ↔ ترمینال
>
> «متاتریدر روی VS Code» نصب نمی‌شود؛ پکیج پایتونی داخل VS Code نصب می‌شود.

> **سمبل پروژه: XAUUSD (طلا)** — نکته اسپرد: اسپرد طلا در بروکرهای معمولی
> حدود ۱۵ تا ۳۵ سنت است (در حساب‌های raw با کمیسیون: ۵ تا ۱۵ سنت).
> عددی که heartbeat نشانت می‌دهد برای انتخاب بروکر آینده حیاتی است.

---

## گام ۱ — نصب پایتون (اگر نداری)

1. برو به [python.org/downloads](https://www.python.org/downloads/)
2. **Python 3.11 یا 3.12** را دانلود و نصب کن
3. ⚠️ در اولین صفحه نصب حتماً تیک **«Add python.exe to PATH»** را بزن
4. چک کن: `py --version` → باید `Python 3.12.x` ببینی

اگه `py` فروشگاه ویندوز را باز کرد → پایتون را از python.org نصص کن (نه Store).

## گام ۲ — دریافت و باز کردن پروژه

1. آخرین نسخه پروژه را بگیر: از PR شماره ۱ در گیت‌هابت (برنچ `arena/01a0864f-gnidart`)
   → Code → Download ZIP → extract (مثلاً `C:\projects\gnidart-trading-bot`)
2. VS Code → **File → Open Folder** → پوشه پروژه
3. اگر پرسید «Do you trust the authors?» → Yes

## گام ۳ — نصب پکیج‌ها

در ترمینال VS Code (**Terminal → New Terminal**):

```powershell
py -m pip install --upgrade pip
py -m pip install -r requirements.txt -r requirements-win.txt
```

## گام ۴ — تست سلامت پروژه (بدون نیاز به MT5)

```powershell
py -m unittest discover -s tests
```

**انتظار:** `Ran 23 tests ... OK`

## گام ۵ — اکانت دمو در MT5

1. ترمینال MT5 → **File → Open an Account**
2. سریع‌ترین راه: **MetaQuotes-Demo** (اکانت مجازی رایگان) — یا بروکر خودت
3. فرم کوتاه → اکانت دمو ساخته می‌شود → لاگین بماند

## گام ۶ — تنظیمات ترمینال

1. دکمه **Algo Trading** در نوار ابزار → **روشن** (سبز)
2. **Tools → Options → Expert Advisors** → تیک **Allow Algorithmic Trading**
3. **Tools → Options → Charts** → **Max bars in chart = Unlimited** ← برای گام ۸ مهم است!
4. ترمینال را یک‌بار بسته و باز کن
5. در **Market Watch** (Ctrl+M) مطمئن شو **XAUUSD** دیده می‌شود

## گام ۷ — اجرای Heartbeat 🫀

در ترمینال VS Code (ترمینال MT5 هم باز بماند):

```powershell
py scripts/mt5_heartbeat.py
```

**خروجی مورد انتظار:** شماره اکانت + ✅ دمو + قیمت طلا + **اسپرد** + جدول کندل‌های M15

## گام ۸ — خروجی داده تاریخی (سوخت فاز ۱: بک‌تست) 📦

دو منبع داده — هر دو را اجرا کن و **فایل‌های خروجی را در چت Arena ضمیمه کن**:

**۸-الف) تاریخچه بروکر خودت (مهم‌ترین):**
```powershell
py scripts/export_mt5_history.py
```
→ خروجی: `data/xauusd_m1_mt5.csv.gz` — فید واقعی بروکر تو؛ مبنای بک‌تست نهایی.

**۸-ب) تاریخچه عمیق Dukascopy (۳ سال):**
```powershell
py scripts/fetch_dukascopy.py --years 3
```
→ خروجی: `data/xauusd_m1_duka.csv.gz` — تاریخچه عمیق و تمیز برای walk-forward.

## گام ۹ — گزارش به منتور

این‌ها را در چت بفرست:
1. خروجی کامل heartbeat (مخصوصاً **اسپرد طلا** — برای انتخاب بروکر آینده حیاتی است)
2. دو فایل csv.gz ضمیمه‌شده از گام ۸

## 🔧 رفع اشکال

| مشکل | راه‌حل |
|---|---|
| `py` شناخته نشد / Store باز شد | پایتون از python.org با تیک PATH |
| `MetaTrader5` نصب نشد | `py --version` → باید 3.9 تا 3.12 باشد |
| `اتصال به ترمینال ناموفق` | ترمینال باز؟ لاگین؟ چند ترمینال داری → مسیر بده |
| `سیمبل 'XAUUSD' پیدا نشد` | پسوند بروکر: `py scripts/mt5_heartbeat.py --symbol XAUUSD.r` (از Market Watch کپی کن) |
| خروجی MT5 خیلی کم کردل داد | Max bars = Unlimited + ری‌استارت ترمینال (گام ۶-۳) |
| کندل‌ها دیشب متوقف شده | بازار آخر هفته تعطیل است — طلا یکشنبه‌شب باز می‌شود |
| دانلود Dukascopy کند | عادی است (~۱۵-۲۵ دقیقه برای ۳ سال)؛ کش روزانه دارد، دوباره‌اجرا ارزان است |
| `HTTP 503` از datafeed | Rate-limit است، نه بلاک. از v0.2.1 خودکار retry + backoff دارد. اگر در پایان `⚠️ N روز هنوز در دسترس نبود` دیدی، فقط همان دستور را دوباره اجرا کن — کش ادامه می‌دهد و فقط روزهای جا‌مانده را می‌گیرد |

## بعد از این مرحله چه می‌شود؟

- **اینجا (سندباکس):** فاز ۱ — موتور بک‌تست event-driven روی دیتای تو + فاز ۲ (رژیم و استراتژی‌ها)
- **ماشین تو:** در فاز ۵ «گره اجرای دمو» می‌شود
- **قانون طلایی:** هیچ پول واقعی تا پاس‌شدن بک‌تست walk-forward + ۲-۳ ماه فوروارد دمو

## گام ۹ (فاز ۵) — اجرای دموی فوروارد

پیش‌نیاز: گام‌های ۱ تا ۸ انجام شده (ترمینال MT5 باز، لاگینِ **اکانت دمو**، Algo Trading سبز).

### روز اول — حالت کاغذی (یک شبانه‌روز)
```
py scripts/run_live.py --dry-run
```
همه‌چیز واقعی است جز سفارش: سیگنال‌ها، رژیم، گیت‌ها، ژورنال — فقط پوزیشن مجازی.
هر ~۲۰ ثانیه یک خط لاگ می‌آید؛ بگذار چند ساعت (ترجیحاً تا فردا) روشن بماند.

### بعدش — دموی واقعی
```
py scripts/run_live.py
```
از این لحظه ربات روی اکانت دمو معامله می‌کند: فقط خرید، فقط سشن لندن/نیویورک (۱۲–۲۰ UTC)،
اسپرد بالای $0.40 = ورود ممنوع، حداکثر ۳ معامله در روز، ۱ پوزیشن باز، ریسک ۰.۵٪ × نردبان بریکر.

**خاموشی امن:** استاپ و تارگت به سفارش چسبیده‌اند و روی سرور بروکر اجرا می‌شوند —
اگر ربات یا اینترنت خاموش شود، پوزیشن‌ها یتیم نمی‌مانند. Ctrl+C = توقف تمیز.

### گزارش هفتگی (مهم‌ترین قسمت!)
```
py scripts/live_report.py
```
خروجی را کامل در چت Arena بفرست تا با هم تحلیل کنیم — این حلقهٔ منتورینگِ ماست.

### رفع توقف (halt)
اگر بریکر پیام `HALT` داد: بعد از اینکه با هم بازبینی کردیم:
```
py scripts/run_live.py --ack
```

| مشکل | راه‌حل |
|---|---|
| `⛔ این اکانت دمو نیست` | به اکانت دمو لاگین کن — ربات روی پول واقعی اجرا نمی‌شود |
| `تیک XAUUSD ناموجود` | Market Watch → سیمبل را نمایش بده |
| هیچ سیگنالی نمی‌آید | عادی است — فقط ~۱۰–۱۵ معامله در ماه انتظار داریم |
| خطای چرخه | ربات خودش ادامه می‌دهد؛ متن خطا را در گزارش هفتگی بیاور |
