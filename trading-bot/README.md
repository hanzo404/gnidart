# 🤖 gnidart-trading-bot

ربات معاملاتی اینترادی فارکس — **پویا، خوداصلاح‌گر و ریسک‌محور**.

> این پروژه حاصلِ منتورشیپ روی کتابخانه ۱۴۷ کتابی trading است:
> روانشناسی (Douglas ×2, Elder ×2) + کندل‌استیک (Nison) + که قرار است ادامه یابد
> (Chan, Carter, Grimes — سه کتاب هایلایت‌شده کاربر).

## تصمیمات قفل‌شده (۲۰۲۶-۰۹-۰۹)

| موضوع | تصمیم | دلیل |
|---|---|---|
| بازار | **فارکس** | دیتای رایگان باکیفیت، M15 عالی کار می‌کند |
| پلتفرم اجرا | **MetaTrader 5** | استاندارد بروکرهای فارکس |
| سرمایه | **اول دمو (۲-۳ ماه فوروارد)** | اثبات سیستم قبل از پول واقعی |
| تایم‌فریم تصمیم | **M15** | هزینه اسپرد ~نصفِ M5، نویز کمتر، هم‌راستا با سطوح نهادی |
| تایم‌فریم روند / ورود | **H1 / M5** | معماری Triple Screen (الدر) |
| ریسک هر معامله | **۰.۵٪** (دمو) | با اثبات لبه → ۱٪ |
| سقف ضرر ماهانه | **۶٪** → توقف کامل | قانون ۶٪ الدر |
| واکنش به ضررهای متوالی | نردبان برق‌گیر (جدول پایین) | نه revenge، نه بازنویسی استراتژی روی نویز |

## معماری

```
DATA LAYER ──► REGIME ENGINE ──► STRATEGY CORE (×3) ──► RISK ENGINE ──► EXECUTION
(dukascopy/MT5)  (روند/رنج/آشفتگی)  (پولبک/بازگشت/     (سایز + استاپ +    (بک‌تست/
                                     شکست — هرکدام      برق‌گیر ضرر)      پیپر/MT5)
                                     فقط در رژیم خود)
       ▲                                                        │
       └──────────── JOURNAL DB + SELF-ANALYSIS ◄───────────────┘
        (هر معامله: فیچرهای لحظه ورود + MFE/MAE + گزارش پست‌مورتم
         + walk-forward ماهانه + بعداً meta-labeling)
```

### نردبان برق‌گیر ضرر (Circuit Breaker) — پیاده‌سازی‌شده ✅

| ضررهای متوالی | واکنش ربات |
|---|---|
| ۲ | حجم ×۰.۵ + صف اسکن تشخیصی |
| ۳ | حجم ×۰.۲۵ + فقط ستاپ‌های A-grade |
| ۴ | توقف ۲۴ ساعته + پست‌مورتم اجباری |
| ۶ (یا ۶−٪ ماهانه) | **توقف کامل** — نیاز به acknowledge (بازاجرای walk-forward) |
| برد در حجمِ کم | بازگشت پله‌ای: ۰.۲۵ → ۰.۵ → ۱.۰ |

**چرا این‌طراف؟** سیستم سودده با نرخ برد ۵۵٪، ۲۰٪ مواقع دو باخت پشت‌سرهم می‌خورد و در
هر ۱۰۰ معامله تقریباً قطعاً رشته ۴-باختی دارد. بازنویسی استراتژی روی همین نویز =
قتل لبه با دست خودمان. پس: **کاهش ریسک + ثبت کانتکست + تحلیل آماری در نمونه بزرگ.**
